# openapi-chain logo

The openapi-chain mark: a blue-to-teal chain link around a `</>` code symbol. Use these files for
the project name in READMEs, slides and social profiles. The website's favicons and app icons live
in [`website/app/`](../../website/app/).

Prefer the cropped `openapi-chain-logo-*` files wherever the mark sits in a layout. The square
`openapi-chain-icon-*` exports keep about 57% empty space above and below the mark for icon grids,
which makes the mark look small in a page.

| File                                | Use                                                     |
| ----------------------------------- | ------------------------------------------------------- |
| `openapi-chain-logo-2048.png`       | Cropped transparent mark, 2048 × 906, for large layouts |
| `openapi-chain-logo-1024.png`       | Cropped transparent mark for READMEs and web pages      |
| `openapi-chain-logo-512.png`        | Cropped transparent mark for small placements           |
| `openapi-chain-logo-black-1024.png` | Cropped one-color black mark                            |
| `openapi-chain-logo-white-1024.png` | Cropped one-color white mark                            |
| `openapi-chain-icon-2048.png`       | Square transparent source for icons                     |
| `openapi-chain-icon-1024.png`       | Square transparent icon for large displays              |
| `openapi-chain-icon-512.png`        | Square transparent icon                                 |
| `openapi-chain-icon-256.png`        | Square transparent icon for small placements            |
| `openapi-chain-black-1024.png`      | Square one-color black icon                             |
| `openapi-chain-white-1024.png`      | Square one-color white icon                             |
| `openapi-chain-dark-1024.png`       | Square avatar on the brand background `#0B1220`         |

Each cropped file is cut from the square export of the same width without resampling. Only rows
whose opacity stays below 4/255 were removed, and a 16/2048 margin remains above and below the mark.
The side margins are unchanged.

The files are raster exports; there is no vector source. Keep the mark's proportions and colors.
