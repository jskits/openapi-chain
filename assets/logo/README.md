# openapi-chain logo

The openapi-chain mark: a blue-to-teal chain link around a `</>` code symbol. Use these files for
the project name in READMEs, slides and social profiles. The website's favicons and app icons live
in [`website/app/`](../../website/app/).

| File                           | Use                                                           |
| ------------------------------ | ------------------------------------------------------------- |
| `openapi-chain-icon-2048.png`  | Highest-resolution transparent source                         |
| `openapi-chain-icon-1024.png`  | Transparent mark for print, slides and large displays         |
| `openapi-chain-icon-512.png`   | Transparent mark for READMEs and web pages (shown at ≤256 px) |
| `openapi-chain-icon-256.png`   | Transparent mark for small placements                         |
| `openapi-chain-black-1024.png` | One-color black mark on transparent backgrounds               |
| `openapi-chain-white-1024.png` | One-color white mark on transparent backgrounds               |
| `openapi-chain-dark-1024.png`  | Square avatar on the brand background `#0B1220`               |

The files are raster exports; there is no vector source. Keep the mark's proportions and colors, and
leave clear space around it rather than cropping to the edges.
