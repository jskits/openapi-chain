# openapi-chain

Compatibility entry points for [`@openapi-chain/core`](https://www.npmjs.com/package/@openapi-chain/core). Existing imports such as `openapi-chain`, `openapi-chain/strict`, and `openapi-chain/metadata` continue to work. New projects should install `@openapi-chain/core`.

```sh
pnpm add @openapi-chain/core
```

See the [migration guide](https://github.com/jskits/openapi-chain/blob/main/docs/migration-to-scope.md).
